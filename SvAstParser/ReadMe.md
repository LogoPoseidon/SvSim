# SvAstParser

SvAstParser is a C# library designed to parse and resolve SystemVerilog AST structures generated by slang. It automatically resolves and links address-based string references into strongly typed object references in-memory.

## Installation

Reference the `SvAstParser` project or assembly within your application. Make sure the `slang` executable is installed and available in your system's PATH variable if you intend to parse SystemVerilog files directly.

## Usage

The library provides a single entry point via the static class `SvParser`. Internal parsing, serialization, and reference-linking details are encapsulated.

### 1. Parsing directly from a SystemVerilog File (.sv)

To compile a SystemVerilog source file in-memory using slang and parse the resulting AST, use `ParseFromSystemVerilogFilePath`:

```csharp
using System;
using SvAstParser;

string svFilePath = "path/to/design.sv";

try
{
    // Compiles in-memory and parses the resulting AST
    TopLevel topLevel = SvParser.ParseFromSystemVerilogFilePath(svFilePath);

    Console.WriteLine($"Parsed design with {topLevel.Definitions.Length} definition(s).");
}
catch (Exception ex)
{
    Console.WriteLine($"Error compiling or parsing design: {ex.Message}");
}
```

### 2. Parsing Multiple SystemVerilog Files with Arguments

If your design spans multiple files or requires specific compiler switches (such as include paths or macro definitions), use `ParseFromSystemVerilogFilePaths`:

```csharp
using System;
using System.Collections.Generic;
using SvAstParser;

var files = ["source1.sv", "source2.sv"];
var args = ["-I", "include/directory", "+define+SIMULATION"];

try
{
    var topLevel = SvParser.ParseFromSystemVerilogFilePaths(
        filePaths: files,
        slangExecutable: "slang", // Can point to a specific slang path if not in system PATH
        additionalArgs: args
    );

    Console.WriteLine("Multi-file design successfully compiled and parsed.");
}
catch (Exception ex)
{
    Console.WriteLine($"Error: {ex.Message}");
}
```

### 3. Parsing a Pre-Generated AST JSON File

If you already have a compiled AST JSON file saved on disk (generated via `slang file.sv --ast-json out.json`), you can parse it directly using `ParseFromAstJsonFilePath`:

```csharp
using System;
using SvAstParser;

string jsonPath = "path/to/ast.json";

try
{
    var topLevel = SvParser.ParseFromAstJsonFilePath(jsonPath);

    if (topLevel.Design is { Members: not null })
    {
        foreach (var member in topLevel.Design.Members)
        {
            Console.WriteLine($"Node Name: {member.Name}, Kind: {member.Kind}");
        }
    }
}
catch (Exception ex)
{
    Console.WriteLine($"Error reading AST JSON: {ex.Message}");
}
```
